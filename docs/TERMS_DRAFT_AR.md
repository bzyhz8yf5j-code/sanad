# شروط الاستخدام — مسودة عربية

> مسودة تشغيلية وليست نصًا قانونيًا نهائيًا.

سند منصة رقمية لتسهيل البحث والتواصل وإدارة المسارات العقارية. المعلومات والخرائط وحالات المعاملة داخل التطبيق لا تُعد بحد ذاتها سند ملكية أو قرارًا حكوميًا أو ضمانًا قانونيًا.

المستخدم أو المكتب مسؤول عن صحة المحتوى الذي يقدمه وامتلاكه الحق في استخدام المستندات والصور. يمنع الاحتيال والمحتوى المضلل وانتحال الصفة وتجاوز الصلاحيات.

علامات التوثيق وتقييمات المخاطر داخل سند أدوات تنظيمية ولا تستبدل التحقق القانوني من الملكية والقيود والموافقات الرسمية قبل أي التزام مالي أو قانوني.

خريطة الأساس للسياق الجغرافي فقط. حدود القطع والمرتسمات الرسمية لا تعتمد إلا عند ربط مصدر مرخّص ومراجع داخل سند.

قبل الإطلاق العام يجب اعتماد شروط نهائية تشمل الجهة المشغلة، حدود المسؤولية، آلية الشكاوى، القانون المختص، ووسائل التواصل والدعم.
