# إدارة مصادر الخرائط والمرتسمات

يدعم سجل `map_sources`: XYZ / WMS / WMTS / WFS / Vector. الإدارة وحدها تملك الإضافة والتعديل والحذف، بينما المستخدم المصادق يرى المصادر المفعلة.

`check-map-source` يسجل وقت الفحص، latency والحالة healthy/degraded/down. يتم رفض HTTP، localhost، عناوين IPv4 الخاصة، host.local، والروابط التي تحتوي بيانات دخول لتقليل مخاطر SSRF.

لا تعني صحة endpoint أن بياناته رسمية؛ حالة الاعتماد القانوني ومصدر البيانات يجب أن يبقيا منفصلين.
