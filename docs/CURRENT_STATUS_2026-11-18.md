## بوابة الإصدار الحالية

حتى تاريخ هذه المراجعة لا يوجد ما يثبت تشغيل EAS Native Build فعليًا أو تثبيت نسخة Development Build على iPhone من سجل المستودع.

قبل التوزيع الفعلي على iPhone نحتاج:
1. تشغيل أول EAS Development Build.
2. إكمال Apple Developer credentials وتسجيل الجهاز عند الحاجة للبناء على جهاز حقيقي.
3. استبدال أيقونة Expo الافتراضية بالأيقونة الرسمية المعتمدة لسند قبل الإطلاق.
4. ضبط Production Map Style URL بدل أي fallback تطويري.
5. تنفيذ اختبار فعلي على الجهاز لمسارات الدخول، النشر، الصور، الخرائط، GPS، الإشعارات والمزامنة Offline.

## ملاحظات تطويرية

- بعض أقسام الخدمات الخاصة موجودة كواجهات أولية وتحتاج تعميق وظيفي قبل اعتبارها مكتملة إنتاجيًا.
- لا يظهر في المسارات الحالية تطبيق مكتمل مستقل لمساعد AI العقاري.
- لا يظهر في المسارات الحالية عارض CAD إنتاجي مرخّص ومتكامل داخل التطبيق.
- يجب إبقاء مقارنة العقارات خارج النطاق لأنها ملغاة بقرار المنتج.
