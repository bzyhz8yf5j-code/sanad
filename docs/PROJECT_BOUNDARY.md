# حدود مشروع سند

هذا المستودع مخصص لتطبيق **سند** العقاري فقط.

## الهوية والنطاق

- الاسم المعتمد: سند.
- النوع: تطبيق عقاري وخدمي.
- النطاق: جميع محافظات العراق.
- التقنية الحالية: Expo / React Native وSupabase / PostGIS.

## الفصل بين المشاريع

- لا تُنقل إلى هذا المستودع ملفات مشروع «السعد».
- لا تُستخدم هوية «السعد» أو شعاره أو أقسامه داخل «سند».
- لا تُنقل إليه ملفات «مجمع البارق».
- أي تطوير جديد هنا يجب أن يخدم وظائف «سند» العقارية فقط.
