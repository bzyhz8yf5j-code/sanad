# أمن سند

## مبادئ
- لا يثق التطبيق بـ role القادم من الجهاز؛ الدور من `profiles` وقواعد RLS.
- الملفات الخاصة لا تُعرض بروابط عامة؛ Signed URLs قصيرة العمر فقط.
- رموز متابعة المعاملات لا تُخزن كنص خام في الإنتاج؛ تحفظ بصمة/Hash فقط.
- القرارات الإدارية واعتماد المهنيين داخل Edge Functions أو SQL Security Definer محدودة ومدققة.
- كل تغيير حساس يكتب Audit Event.
- Rate limit يطبق على: حل رموز المعاملات، روابط المشاركة، OTP، الرسائل، رفع الملفات والبحث المكثف.
- بيانات الموقع والمستندات تعامل كبيانات حساسة، وتحدد مدة الاحتفاظ والحذف في سياسة الخصوصية.

## تحذير تنفيذ
المهاجرات الحالية أساس هندسي وليست اعتمادًا أمنيًا نهائيًا. يجب تشغيل اختبارات RLS بمستخدمين متعددين قبل أي إطلاق تجريبي عام.
