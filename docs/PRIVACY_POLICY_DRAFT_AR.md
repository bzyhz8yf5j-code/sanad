# سياسة الخصوصية — مسودة عربية

> مسودة تشغيلية وليست نصًا قانونيًا نهائيًا.

سند يجمع البيانات اللازمة لتشغيل الحساب والخدمات التي يختارها المستخدم، ومنها بيانات الحساب، العقارات والوسائط، المفضلة، البحث المحفوظ، الرسائل، المواعيد، المعاملات، بيانات المكتب أو الاعتماد المهني، وبيانات الموقع/الكاميرا عند استخدام العمل الميداني.

يستخدم سند بيانات الموقع والصور فقط في الوظائف التي تتطلبها. رموز Push ترتبط بالحساب والجهاز وتُعطل عند تسجيل الخروج أو بدء طلب حذف الحساب أو عند إبلاغ مزود الإشعارات أن الجهاز غير مسجل.

يمكن للمستخدم بدء طلب حذف الحساب من داخل التطبيق. تعالج البيانات الشخصية القابلة للحذف ضمن هذا المسار، بينما قد تحتاج بعض سجلات المعاملات والتدقيق أو الملفات المرتبطة بالتزامات سارية إلى احتفاظ أطول أو إخفاء هوية بدل الحذف الفوري.

المفاتيح الإدارية السرية لا تُخزن في تطبيق المستخدم. الوصول إلى البيانات يخضع للمصادقة وسياسات RLS وخدمات backend.

قبل الإطلاق العام يجب اعتماد النص قانونيًا، تحديد جهة التحكم بالبيانات ووسيلة التواصل، مدد الاحتفاظ النهائية، حقوق المستخدم، ونشر نسخة HTTPS عامة متطابقة مع إعدادات المتجر.
