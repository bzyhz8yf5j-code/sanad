# خطة اختبار RLS

يجب تشغيل هذه الحالات بعد ربط Supabase محليًا:

1. مواطن لا يستطيع إنشاء إعلان باسم مكتب.
2. موظف `agent` يستطيع إنشاء/تعديل مسودة لكنه لا يستطيع النشر.
3. `manager` يستطيع النشر لمكتب معتمد فقط.
4. عضو مكتب A لا يستطيع قراءة ملفات مكتب B الخاصة.
5. مستخدم غير عضو في المحادثة لا يستطيع قراءة الرسائل.
6. مقدم طلب مهني يقرأ طلبه فقط، ولا يستطيع اعتماده.
7. supervisor/admin يستطيع مراجعة المهنيين والخدمات لكن لا يحصل على ملفات خاصة غير لازمة إلا عبر السياسات المصرح بها.
8. property media private؛ لا public URL.
9. إشعارات المستخدم لا تُقرأ من مستخدم آخر.
10. Audit log غير متاح للمواطن والمكتب.
11. دعوة المكتب لا تقبل إلا البريد المدعو، قبل الانتهاء، ولمرة واحدة.
12. رمز متابعة المعاملة يعيد فقط parties/events الموسومة `visible_to_client=true`.
