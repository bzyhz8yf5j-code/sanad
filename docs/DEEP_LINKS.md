# Deep Links والإشعارات

Scheme التطبيق: `sanad://`.

بيانات Push تستخدم `topic` و`entityId`. طبقة `deepLinks.ts` تحولها إلى مسار آمن داخل Expo Router، وتشمل العقار، المحادثة، المعاملة، القطعة وطلبات الخدمات.

الروابط الخاصة بالعقار تفتح شاشة العرض العامة، وليس شاشة تحرير المكتب، حتى لا يتحول تنبيه البحث المحفوظ إلى مسار ذي صلاحيات تحرير.
