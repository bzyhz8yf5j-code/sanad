# سجل نقل مشروع سند

## النسخ المعتمدة

- الكود والتطبيق: `sanad-platform v0.12.0`.
- حزمة التصميم والتسليم: `Sanad Design Handoff v2`.
- الفرع الرئيسي: `main`.

## محتوى النقل

- تطبيق Expo / React Native.
- خدمات وواجهات Supabase.
- migrations وEdge Functions واختبارات RLS.
- ملفات EAS وGitHub Actions.
- وثائق التشغيل والبناء.
- دليل التصميم النهائي والنموذج التفاعلي وخطة الخرائط.

## ما لم يُضف إلى المستودع

لم تُضف حزم ZIP القديمة والإصدارات السابقة لأنها نسخ أرشيفية مكررة وليست جزءًا من المصدر الحالي. كما استُبعدت أي ملفات لا تخص مشروع «سند».
