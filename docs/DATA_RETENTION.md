# سياسة الاحتفاظ بالبيانات — مسودة تقنية

هذه مسودة تقنية تحتاج اعتمادًا قانونيًا وتشغيليًا قبل الإنتاج.

- Audit events: احتفاظ افتراضي مقترح 24 شهرًا، ثم أرشفة/حذف عبر service role فقط.
- تقارير PDF: روابط العرض موقعة وقصيرة العمر؛ الملف الأصلي الخاص يخضع لسياسة احتفاظ المشروع.
- ملفات العقار والمعاملات: لا تُحذف تلقائيًا طالما توجد معاملة قانونية/نزاع/التزام حفظ.
- Push tokens: يعطل الرمز عند فشل دائم أو تسجيل خروج/إلغاء موافقة المستخدم.
- الصور والوسائط: الحذف المنطقي للإعلان لا يعني بالضرورة الحذف الفوري إذا كان مرتبطًا بمعاملة أو سجل تدقيق.
- النسخ الاحتياطية: يجب تحديد RPO/RTO قبل الإطلاق وربط اختبارات استعادة دورية، وليس الاكتفاء بوجود backup provider.
