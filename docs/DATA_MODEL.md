# نموذج البيانات المختصر

- `profiles`: المستخدم ودوره.
- `offices`, `office_members`: المكتب وصلاحيات الفريق.
- `professional_applications`: طلبات اعتماد مهندس/مثمن.
- `map_sources`, `parcels`: مصادر الخرائط والقطع الهندسية PostGIS.
- `parcel_documents`, `alignment_control_points`, `document_alignments`: المستند الأصلي والمطابقة.
- `properties`, `property_media`: الإعلان ووسائطه.
- `favorites`, `saved_searches`: تخصيص المواطن والتنبيهات.
- `transactions`, `transaction_parties`, `transaction_events`: متابعة المعاملة.
- `service_requests`: استثمر معنا/الأسهم/الأقساط/المجمعات.
- `conversations`, `conversation_members`, `messages`, `appointments`: التواصل والمواعيد.
- `risk_flags`, `processing_jobs`: رادار المخاطر والمعالجة الثقيلة.
- `share_links`, `notifications`, `push_devices`, `audit_events`: المشاركة والتنبيهات والتدقيق.
