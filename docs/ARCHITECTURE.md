# معمارية سند MVP

## الواجهة
- Expo SDK 57 + React Native 0.86 + Expo Router.
- نفس المصدر للآيفون والأندرويد والويب.
- شاشات RTL وهوية كحلي/ذهبي.

## الخرائط
- المرحلة الحالية: `MapSurface` خفيف وقابل للاستبدال.
- الهاتف: `@maplibre/maplibre-react-native` داخل Development Build.
- الويب: `maplibre-gl`.
- الخرائط الإنتاجية تحتاج مزود بلاطات/Style مرخص، ولا تعتمد Demo Tiles.

## CAD
واجهة `CadViewer` لا ترتبط بمزود بعينه. الربط التالي يكون عبر Adapter مع:
1. SDK مرخص لـ DWG/DXF.
2. خدمة خلفية لإنشاء Preview/PDF/thumbnail.
3. طابور jobs للملفات الثقيلة.

## البيانات
- Supabase Auth + PostgreSQL + PostGIS + Storage.
- جداول منفصلة للقطع، الأصول، نقاط التحكم، المطابقات، المخاطر، روابط المشاركة وسجل التدقيق.
- RLS يمنع الوصول غير المصرح ويخصص المراجعة للمشرف والإدارة.

## التسلسل القادم
1. إنشاء مشروع Supabase وربط البيئة.
2. تشغيل migrations وتوليد أنواع TypeScript.
3. إدخال MapLibre الحقيقي ومصدر خريطة العراق.
4. بناء رفع الملفات إلى Storage وطابور المعالجة.
5. إضافة تسجيل الدخول وMFA للمكاتب والإدارة.
6. اختبار أولي مع مكتبين عقاريين ومهندس مساحة.
