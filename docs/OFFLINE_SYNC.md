# Offline Sync Contract

تحتفظ النسخة الخفيفة بطابور تغييرات محلي صغير للعمليات النصية والبيانات الوصفية. كل عملية تحديث تحمل `baseRevision`، بينما يحمل العقار في الخادم `revision` متزايدًا تلقائيًا.

- إذا كان `baseRevision == remoteRevision`: يمكن تطبيق التعديل.
- إذا اختلفا: تسجل حالة تعارض ولا يُستبدل تعديل الخادم تلقائيًا.
- إذا حُذف الكيان في الخادم: تظهر حالة `remote_deleted`.
- الملفات والصور الكبيرة لا تحفظ داخل SecureStore؛ تبقى ضمن cache/media adapter منفصل عند ربط بيئة الأجهزة الفعلية.

هذه الطبقة تمنع الكتابة العمياء فوق نسخة أحدث، وتجهز سند لمزامنة أوسع عند تفعيل التخزين المحلي الإنتاجي.
