# خطة تنفيذ مركز سند الجغرافي العقاري

## MVP - الإصدار الأول
1. الحسابات والأدوار: مواطن، مكتب، مهندس، مثمن، مشرف جغرافي، إدارة.
2. خريطة العراق والبحث الإداري: محافظة، قضاء، ناحية، حي، مقاطعة، قطعة.
3. ملف القطعة العقارية وربطه بالإعلانات والمعاملات.
4. رفع DWG/DXF/PDF/KML/GeoJSON/GeoTIFF وإنشاء معاينات.
5. عارض CAD: طبقات، تكبير، قياس، تعليقات وتصدير PDF.
6. روابط مشاركة مؤقتة، علامة مائية، QR، سجل فتح وتنزيل.
7. لوحة إدارة المصادر والطبقات والمراجعة وسجل التدقيق.
8. الوضع الخفيف والتنزيل الانتقائي وطابور المزامنة.

## المرحلة الثانية
- المطابقة اليدوية بثلاث نقاط والتحكم بالشفافية والدوران والمقياس.
- درجة ثقة ورادار مخاطر أولي.
- الوضع الميداني: GPS وصور وملاحظات وحدود تقريبية.
- بصمة سند المكانية والتقرير الشامل.

## المرحلة الثالثة
- OCR لأرقام القطع والمقاطعات.
- اقتراح موضع تلقائي ومقارنة الأبعاد.
- تكامل مع مصادر رسمية WMS/WMTS/WFS عند توفر الاتفاقات.
- ربط البلديات والتسجيل العقاري والجهات المرخصة.

## بنية تقنية مقترحة
- التطبيقات: Flutter أو Native iOS/Android + Web.
- الخرائط: MapLibre/Mapbox-compatible vector tiles.
- البيانات المكانية: PostgreSQL + PostGIS.
- التخزين: S3-compatible object storage مع versioning.
- المعالجة: خدمة مستقلة لتحويل CAD وإنشاء previews وPDF.
- الطوابير: Background jobs للملفات الثقيلة والمزامنة.
- الأمان: RBAC، MFA للمكاتب والإدارة، روابط موقّتة، تشفير وسجل تدقيق.

## متطلبات خارجية
- ترخيص CAD SDK رسمي.
- مصدر خرائط أساسي مرخص.
- اتفاقات بيانات القطع والمرتسمات الرسمية.
- سياسة خصوصية وشروط استخدام توضح أن الملف داخل سند لا يستبدل وثيقة الملكية الرسمية.
